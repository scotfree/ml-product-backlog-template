# Design decisions log

## Description

_Not what you did — why. Especially why you didn't do the obvious other thing._

## Upstream / Downstream contract

_Future maintainers and reviewers need this to avoid repeating dead ends._

## Definition of Done

_A running doc with 5–15 entries: decision, alternatives considered, reasoning._

## Demo

_Read out one entry; explain the tradeoff._

## Subtasks

- _Add an entry whenever a decision would take more than 5 minutes to re-derive._

## Estimate

_Rough size — minutes, hours, or days. If it's more than a few days, break it up._
