# Portfolio-quality writeup

## Description

_The artifact you'd show in an interview. Short, honest, specific._

## Upstream / Downstream contract

_You. Your interviewers._

## Definition of Done

_2–4 pages (or equivalent slides): what you built, key decisions, what worked, what you'd do next._

## Demo

- _Present it to the team in 5 minutes._
- _Get feedback._

## Subtasks

- _Include real numbers, not marketing._
- _Include one thing that didn't work and what you learned._

## Estimate

_Rough size — minutes, hours, or days. If it's more than a few days, break it up._
