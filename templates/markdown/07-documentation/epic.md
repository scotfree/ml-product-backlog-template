# Epic: Documentation

## What this epic covers

What future-you, your teammates, and the next team need to know. Documentation isn't a report at the end — it's an artifact of doing the work well as you go.

## Cards in this epic

1. README that lets someone reproduce a run
2. Design decisions log
3. Portfolio-quality writeup

## Success criteria

_How will you know this epic is done? What's the demoable outcome — e.g. a newcomer reproduces a run from the README alone, and every non-obvious decision has a recorded reason?_
