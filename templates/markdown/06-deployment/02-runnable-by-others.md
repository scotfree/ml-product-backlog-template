# Runnable by someone who isn't you

_Hand it to a teammate. They set it up with only the README. Anywhere they get stuck is a bug._

- **Upstream/downstream:** _Whoever consumes the model must be able to install and start it without your help._
- **Definition of done:** _A teammate follows the README on a clean machine and produces a working inference in under 15 minutes._
- **Demo:** _Have the teammate demo it, not you._
- **Subtasks:**
  - _Instructions for install, config, and one example call._
  - _Fix whatever tripped the teammate up._
