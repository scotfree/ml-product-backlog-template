# Error analysis

## Description

_Look at what the model gets wrong. Draw conclusions._

## Upstream / Downstream contract

- _Modeling uses this to decide what to try next._
- _Documentation captures what you learned._

## Definition of Done

_A short doc: top 3–5 failure modes, with example inputs and hypotheses for causes._

## Demo

_Walk through 3 examples the model gets wrong; explain what's happening._

## Subtasks

- _Pull worst-scoring examples._
- _Look for patterns (class, size, lighting, whatever's relevant)._
- _Note anything that looks like a data problem vs. a modeling problem._

## Estimate

_Rough size — minutes, hours, or days. If it's more than a few days, break it up._
