# Error analysis

_Look at what the model gets wrong. Draw conclusions._

- **Upstream/downstream:** _Modeling uses this to decide what to try next. Documentation captures what you learned._
- **Definition of done:** _A short doc: top 3–5 failure modes, with example inputs and hypotheses for causes._
- **Demo:** _Walk through 3 examples the model gets wrong; explain what's happening._
- **Subtasks:**
  - _Pull worst-scoring examples._
  - _Look for patterns (class, size, lighting, whatever's relevant)._
  - _Note anything that looks like a data problem vs. a modeling problem._
