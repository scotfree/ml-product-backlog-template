# Epic: Model analysis

## What this epic covers

Is the model itself any good? Metrics on a held-out set, error analysis, comparisons across runs. Answers the question: _"is our model learning the right thing?"_

Distinct from Product analysis, which asks whether the end-to-end system works.

## Cards in this epic

1. Define evaluation metrics
2. Reproducible evaluation harness
3. Error analysis

## Success criteria

_How will you know this epic is done? What's the demoable outcome — e.g. anyone on the team can run one command and get trustworthy, comparable numbers, plus a named set of failure modes?_
