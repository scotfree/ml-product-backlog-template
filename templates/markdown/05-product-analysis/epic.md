# Epic: Product analysis

Does the end-to-end system actually do the job? A good model in a bad system is a bad product. Answers the question: _"if a stranger picked this up and used it, would it work?"_

Distinct from Model analysis, which asks whether the model itself is any good.

## Cards in this epic

1. End-to-end tests on realistic inputs
2. Integration and edge-case tests
3. Hand-off test — someone else runs it
