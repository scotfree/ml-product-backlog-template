# Hand-off test — someone else runs it

_The real test: a teammate not on this project uses the system without your help. Where they stumble is a bug._

- **Upstream/downstream:** _Deployment and documentation both depend on the outcome._
- **Definition of done:** _A named person outside the immediate work stream can run the system end-to-end using only the README, and produce a correct output on a realistic input._
- **Demo:** _Have that person demo it, not you. Note anything they had to ask about._
- **Subtasks:**
  - _Pick the tester in advance so scheduling doesn't block._
  - _Watch them (don't help) and take notes._
  - _File follow-up issues for every stumble._
