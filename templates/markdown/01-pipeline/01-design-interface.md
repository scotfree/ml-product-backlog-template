# Design the pipeline interface

## Description

_Sketch the stages, their inputs, and their outputs. Decide before you code._

## Upstream / Downstream contract

- _Who consumes your final output?_
- _What format do they expect?_

## Definition of Done

_A one-page diagram or doc that a teammate can read and know what each stage sends and receives._

## Demo

_Walk the team through the diagram in 2 minutes; take questions._

## Subtasks

- _List the stages._
- _For each stage, name its input and output types._
- _Identify where stages need to be swappable (mock vs. real)._

## Estimate

_Rough size — minutes, hours, or days. If it's more than a few days, break it up._
