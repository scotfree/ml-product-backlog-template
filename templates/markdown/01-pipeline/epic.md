# Epic: Pipeline

## What this epic covers

The code that moves data through stages, from input to output. Focus on interfaces between stages before focusing on what any stage actually does.

## Cards in this epic

1. Design the pipeline interface
2. Build a stub pipeline end-to-end
3. Replace stubs with real components (incremental)

## Success criteria

_How will you know this epic is done? What's the demoable outcome — e.g. the full pipeline runs on one command, with every stage real?_
