# Shared integration environment

A running instance of the full stack (or the parts that are ready) where teams can test end-to-end integration.

### Upstream / Downstream contract

Team-internal.

### Cross-team contact points

- **All teams** use this for integration testing beyond their own Compose. Owned by T7.
- Timing: Week 3 Foundation Gate.

### Definition of Done

- Environment reachable by all teams
- Runbook for common operations
- Basic auth or shared access

### Demo

Every team can point their service at the shared environment; end-to-end flow works.
