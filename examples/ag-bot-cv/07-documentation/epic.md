# Epic: Documentation (Ag-Bot-CV)

## What this epic covers

The README, decisions log, and final writeup. All written as work happens, not backfilled at the end. Portfolio-quality writeup at the end is a hire-relevant artifact for each student.

## Cards in this epic

1. README that lets someone reproduce a run
2. Design decisions log
3. Portfolio-quality writeup

## Success criteria

A student from another team reproduces the fruit training run from the README without asking questions, `docs/decisions.md` has 10–15 entries, and every student has a writeup naming what they personally owned. Demoable as that outside student showing what they did.
