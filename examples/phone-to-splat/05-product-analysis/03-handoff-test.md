# Hand-off test — someone else runs it

Someone not on the team (another bootcamp team's student, a mentor, a friend) captures a video with their own phone and runs the CLI. They shouldn't have to ask questions. Anywhere they stumble is a bug in the docs or the packaging.

- **Upstream/downstream:** Deployment (Card 06-deployment/02) is the target consumer. Documentation (Card 07-documentation/01) is where the fixes land.
- **Definition of done:** A named person outside the team installs the CLI, captures a video with the documented protocol, runs the pipeline, and gets a viewable 3D file + accuracy report within 30 minutes. Every stumble filed as a GitHub issue.
- **Demo:** Have that person demo it, not the team.
- **Subtasks:**
  - Schedule 45 minutes with the tester in advance.
  - Watch without helping; take notes on every hesitation.
  - Fix every stumble before the demo.
  - If the tester's capture is bad (e.g., their orbit was too fast), that's *also* a doc bug — the capture protocol wasn't clear enough.
