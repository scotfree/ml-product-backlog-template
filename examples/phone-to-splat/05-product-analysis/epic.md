# Epic: Product analysis (Phone-to-Splat)

Does the *system* work end-to-end? Someone hands you a phone video of an object; can you produce a usable 3D file with a trustworthy accuracy score? Tests on realistic new inputs (not from the corpus), edge cases (short videos, out-of-scope objects, broken uploads), and a hand-off test to someone outside the team.

## Cards in this epic

1. End-to-end tests on new inputs
2. Integration and edge-case tests
3. Hand-off test — someone else runs it
