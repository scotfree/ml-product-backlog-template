# Epic: Deployment (Phone-to-Splat)

Package as a pip-installable CLI. Someone installs it, points it at a video, gets a 3D file + accuracy report. Also: recommend and document a viewer (SuperSplat for splats, Blender for glTF/mesh) — deployment includes the consumer story, not just the producer.

Different flavor from ag-bot-cv (no edge device, no long-lived process). Similar shape: package it, someone else runs it, benchmark it on realistic hardware.

## Cards in this epic

1. Package as a CLI
2. Runnable by someone who isn't you
3. Benchmark and document compute requirements
