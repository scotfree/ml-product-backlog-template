# Portfolio-quality writeup

Each student produces a 2–4 page writeup for interviews.

- **Upstream/downstream:** The student's future interviewers.
- **Definition of done:** Each student has `writeups/<name>.md` (or linked blog post). Real numbers, real recent-event prediction, honest failure story.
- **Demo:** Present to team in 5 minutes each; team gives feedback.
- **Subtasks:**
  - Real numbers (per-region IoU, cold/warm latency, model size).
  - **Include one real-world recent flood event prediction as a headline visual.** Visually compelling and easy for a non-technical interviewer to appreciate.
  - One "didn't work" story with lesson learned.
  - Personal contribution clear — this is a portfolio piece.
  - Angle for this project: emphasize the *geographic generalization* work (event-based splits, per-region breakdown). Understanding how models fail across regions is rare and interview-visible.
