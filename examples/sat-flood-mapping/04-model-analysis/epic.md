# Epic: Model analysis (Sat-Flood-Mapping)

Is the model actually good at flood mapping? Segmentation metrics are only the start — for a system that could inform disaster response, false negatives (missed flood pixels) and false positives (crying wolf) have very different real-world costs. Per-region breakdowns matter more than headline mean-IoU.

## Cards in this epic

1. Define evaluation metrics
2. Reproducible evaluation harness
3. Error analysis
